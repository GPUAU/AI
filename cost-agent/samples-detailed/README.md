# 상세 IDC 청구서 샘플 (AI Factory 규모)

`samples/`(a~i)는 랙 몇 개 규모의 단순 양식입니다. 여기 5종은 계약전력 320kW~1MW 규모이고,
실제 청구서에서 자주 보이는 열 구조와 원가를 틀리게 만드는 함정을 일부러 넣었습니다.
사업자 이름·계좌·금액은 모두 가상입니다.

- 만들기: `python scripts/make_detailed_samples.py`
- 채점: `python scripts/score_detailed_samples.py` (키워드 규칙) · `--llm` (설정된 LLM, 금액은 가려서 전송)
- 정답표: `answer_key.json` — 줄마다 역할·원가 항목·기간, 항목별 연간 원가, 함정 목록

## IDC 청구서는 보통 이렇게 생겼다

```
┌ 머리글 블록 ─ 사업자, 고객, 계약번호, 청구월·이용기간, 계약전력(kW), 랙 수, 금액 단위·VAT 여부
├ 명세 표 ──── [구분] 항목 [산정기준] [수량] [단위] [단가] 금액 … (금액 열이 1~3개)
├ 합계부 ───── 소계 / 공급가액 / 부가세 / 당월 청구금액 / (전월 미납·입금) / 납부할 금액
└ 안내문 ───── 납부기한, 계좌, 문의처, "회선은 별도 계약" 같은 비고
```

| 열 | 흔한 이름 | 원가 계산에 쓰는가 |
|---|---|---|
| 구분 | 상면·전력·네트워크·운영 | 분류 힌트 |
| 항목 | 청구항목, Description | **분류의 핵심** |
| 산정기준 | 계약 25랙, 744,000kWh × 183원 | 검증 힌트 (수량 × 단가) |
| 수량·단위·단가 | Qty, UoM, Unit Rate | 금액 열로 착각하면 안 됨 |
| 금액 | 금액 / 공급가액·부가세·합계 / MRC·NRC / 월 정액·당월 청구액 | **어느 열을 쓰는지가 핵심** |
| 비고 | 일할 계산, 1회 청구, 별도 계약 | 기간·누락 판단 |

## 5종 요약

| 파일 | 상황 | 열 구조 | 주요 함정 |
|---|---|---|---|
| r1 `kr_metered_krw` | 국내 1MW 고밀도 구역, 월 청구 | 공급가액·부가세·합계 열이 줄마다 | 합계 열 선택 시 +10%, '전력용량 기반 상면 이용료' 오분류, 총액 줄 2개 |
| r2 `multisheet_thousand_krw` | 512kW 전용구역, 3시트 | 요약 / 상세(그룹 소계) / 일별 kWh | **천원 단위**, 소계·요약 중복, 1회성 공사비 |
| r3 `colo_mrc_nrc_usd` | 해외 코로케이션 800kW | MRC·NRC 두 금액 열 | NRC를 ×12, SLA 크레딧, 이월 잔액·입금 줄 |
| r4 `prorated_first_month_krw` | 신규 입주 첫 달(17일) | 월 정액·당월(일할) 청구액 | 일할 금액 ×12 → 45% 과소, 회선 별도 계약(누락) |
| r5 `quarterly_no_currency` | 3분기 일괄 청구 | 2줄 병합 머리글 | **분기 청구**(×4), 통화 표시 없음, 운영비 자체 인력 |

| 샘플 | 줄 분류 | 총액 대조 | 연간 운영원가 / 정답 | 1회성 (얻음/정답) |

| r1 | 13/16 | 불일치 | 2.2배 | 0 / 0 |

| r3 | 10/16 | 불일치 | 2.81배 | 0 / 73,000 |
| r4 | 7/7 | 일치 | 0.553배 (일할 ×12) | 3,000,000 / 3,000,000 |
| r5 | 7/7 | 일치 | 3배 (분기를 월로) | 0 / 0 |

r4·r5는 **줄 분류와 총액 대조가 모두 맞는데 연간 원가가 틀립니다.** 총액 대조만으로는 원가를 믿을 수 없다는 근거입니다.
